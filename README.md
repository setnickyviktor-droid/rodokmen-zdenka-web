# Rodokmeň – Zdenka

Zašifrovaná webová stránka rodokmeňa: https://setnickyviktor-droid.github.io/rodokmen-zdenka-web/

Obsah je chránený heslom a dešifruje sa až v prehliadači (AES-256-GCM, kľúč PBKDF2-SHA256, 600 000 iterácií). Bez hesla nie sú údaje čitateľné.

Stránka sa generuje zo súkromného výskumného repozitára; tento repozitár obsahuje len výsledný súbor `index.html`.
